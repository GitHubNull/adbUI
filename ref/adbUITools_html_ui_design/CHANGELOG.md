# Changelog

本项目变更记录,格式遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/),
版本号遵循 [语义化版本](https://semver.org/lang/zh-CN/)。

## [0.2.0] - 2026-08-20

### Added
- 新增显示调节功能:分辨率 / DPI 预设与自定义、过扫描无级调节、动画速度 / 字体 / 锁屏时间调节
- 新增电池模拟功能:模拟电量 / 温度 / 充电状态,一键还原真实电池状态
- 新增设备控制功能:重启系统 / Recovery / Bootloader / Fastboot,点击 / 滑动 / 长按 / 物理按键 / 文本输入模拟
- 新增自动化脚本功能:脚本录制 / 编辑 / 执行,支持导入导出与执行中停止
- 新增常用命令库:高频 ADB 指令分类一键执行,支持收藏与自定义,与命令历史联动
- 新增 src/js/adb.js ADB 引擎抽象层(Mock 实现,为桌面化替换真实引擎预留统一接口)
- 新增 doc/M2_PLAY_CORE_PLAN.md 玩机核心详细实施规划文档

### Changed
- 项目定位调整为跨平台 PC 端 ADB 设备管理应用的 UI 前期设计探索,同步更新 README.md、AGENTS.md 与 doc/ROADMAP.md 的相关表述

## [0.1.0] - 2026-08-18

### Added
- 新增任务中心视图,集中展示后台任务执行状态
- 新增设备信息视图,查看设备详情与系统参数
- 应用管理支持批量卸载与批量清除数据
- 文件管理支持拖拽上传与文件推送
- 新增设置页,支持配置持久化保存与恢复默认
- 新增 doc/ROADMAP.md 功能规划路线图
