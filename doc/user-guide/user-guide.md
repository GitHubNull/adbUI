## 简介与功能总览

adbUI 是一款基于 Tauri (Rust + Vue) 的跨平台 ADB (Android Debug Bridge) 桌面应用。它通过图形化界面替代繁琐的命令行操作，让您轻松管理 Android 设备。

目前提供 **12 个功能模块**（11 个功能页 + 设置）：

| 模块 | 一句话说明 |
|------|-----------|
| 设备管理 | 实时检测已连接设备，支持无线连接（扫码配对/手动/扫描），展示详细信息与完整报告 |
| 应用管理 | 查看设备上所有应用，支持卸载、冻结、提取 APK、图标展示与详情弹窗 |
| 文件管理 | 浏览设备文件系统，支持上传、下载、类型筛选与图片预览 |
| 日志查看 | 实时查看设备 logcat 日志输出，支持级别/Tag/PID 筛选与搜索 |
| Shell 终端 | 交互式执行 ADB Shell 命令，内置常用命令库与命令历史抽屉 |
| 截图录屏 | 设备截图预览与保存（自适应缩放），屏幕录制（部分设备受限） |
| 性能监控 | 实时展示 CPU、内存、温度和进程列表 |
| 任务中心 | 批量操作（安装/卸载）的进度跟踪与管理 |
| 显示调节 | 查看和修改分辨率、密度、过扫描与系统参数（动画/字体/锁屏） |
| 电池管理 | 模拟电量、温度和充电状态，一键还原真实电池 |
| 自动化脚本 | 多行 ADB 命令脚本流式执行，内置输入模拟与设备重启 |
| 设置 | 主题切换、超时设置、轮询间隔、图标缓存目录 |

## 安装

### 系统依赖

adbUI 基于 Tauri 2 构建，在 Linux 上需要以下系统依赖：

```bash
# Debian / Ubuntu
sudo apt update
sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file libxdo-dev libssl-dev pkg-config

# 确保已安装 Node.js (>= 18) 和 pnpm
# 参见 https://v2.tauri.app/start/prerequisites/
```

### 从源码构建

```bash
# 1. 克隆仓库
git clone <repository-url>
cd adbUI

# 2. 安装前端依赖
pnpm install

# 3. 启动桌面端（开发模式）
pnpm tauri dev

# 4. 打包桌面应用（生成 .deb 安装包）
pnpm tauri build
```

打包完成后，安装包位于 `src-tauri/target/release/bundle/deb/` 目录下。

> 注意：adbUI 通过 Rust 库 `adb_client` 直连 ADB 服务，**无需**本机单独安装 adb 命令行工具。

## 快速上手

### 连接设备

1. **USB 连接**：在 Android 设备上开启「开发者选项」->「USB 调试」，通过 USB 线连接到电脑
2. **WiFi 连接**：点击设备管理页面的「无线连接」按钮，在对话框中任选一种方式：
   - **扫码连接**：生成配对二维码，手机扫码后自动完成 mDNS 配对与连接（需 Android 11+）
   - **手动输入**：输入设备 IP 与端口（默认 5555）后连接（设备需先通过 `adb tcpip 5555` 开启无线调试）
   - **扫描连接**：自动扫描局域网内的 ADB 设备，选择后一键连接

### 界面布局

adbUI 界面分为三大区域：

- **左侧边栏**：12 个功能模块的导航入口（11 个功能页 + 底部设置），点击切换视图，支持折叠
- **右侧主内容区**：当前选中模块的操作界面
- **底部状态栏**：实时显示数据同步状态（实时 / 轮询降级）、在线设备数与 USB / WiFi 统计、运行中任务数与当前视图

首次启动时，adbUI 会自动检测已连接的设备并展示在「设备管理」页面。

## 各功能模块详解

以下按侧边栏顺序逐一说明。

### 1. 设备管理

- 通过 WebSocket 实时推送检测设备状态变化（不可用时自动降级为 5 秒轮询，页面隐藏时暂停）
- 显示设备 ID、型号、连接方式（USB / WiFi），支持对 WiFi 设备一键断开
- 点击设备查看详情：品牌、Android 版本、SDK 版本、构建号、电量等
- 详情面板可展开「完整报告」：聚合 getprop 与 dumpsys，展示型号、CPU ABI、序列号、电池、显示参数等，支持导出 JSON
- 点击「无线连接」打开连接对话框：扫码配对 / 手动输入 IP:端口 / 局域网扫描三页签
- 点击「刷新」按钮手动刷新设备列表

### 2. 应用管理

- 查看设备上所有已安装应用，支持按「全部 / 用户应用 / 系统应用」筛选与搜索
- 自动提取并展示应用图标（设备端 dex 提取器，无需 root，本地磁盘缓存）
- **双击应用**打开详情弹窗：安装来源、APK 大小、目标 SDK 版本等
- **卸载应用**：选中应用后点击卸载（系统应用需 root）
- **强制停止**：立即停止应用运行
- **清除数据**：重置应用数据（相当于「清除存储」）
- **冻结 / 解冻**：禁用/启用应用（系统应用需 root，谨慎操作）
- **提取 APK**：将应用 APK 导出到本地
- **安装 APK**：选择本地 APK 文件安装到设备
- **批量卸载 / 批量安装**：通过任务中心跟踪进度

> 警告：冻结系统应用可能导致设备不稳定，请谨慎操作。

### 3. 文件管理

- 浏览设备文件系统，支持目录导航和面包屑路径
- 支持按文件类型筛选（图片/视频/音频/文档/压缩包/APK，目录始终显示）
- **上传文件**：点击上传按钮，选择本地文件推送到设备当前目录
- **下载文件**：选中文件后点击下载，拉取到本地
- **图片预览**：双击图片文件（10MB 内）在抽屉中预览，支持缩放查看

### 4. 日志查看

- 实时捕获设备 logcat 输出（快照模式，自动刷新）
- 支持按日志级别筛选（Verbose / Debug / Info / Warn / Error / Fatal）
- 支持按 Tag、PID 筛选与文本搜索
- 支持暂停查看与清空日志

### 5. Shell 终端

- 交互式 ADB Shell 命令执行
- 支持命令历史记录，按上下键快速回看
- 错误输出高亮显示
- 输入命令后按回车执行，输出实时显示
- **常用命令库抽屉**：分类浏览内置命令模板，支持收藏、添加、编辑、删除自定义命令，一键执行
- **命令历史抽屉**：搜索、重跑、复制、清空历史记录

### 6. 截图录屏

- **截图**：进入页面或切换设备时自动捕获，也可点击「截图」按钮手动捕获
- **预览**：自适应缩放开关按容器大小等比缩放完整显示（缩放上限 1 不放大），关闭时按原始分辨率 1:1 显示（可滚动）；预览模拟手机外边框，缩放时显示比例徽章
- **保存截图**：点击「保存」按钮，通过系统对话框选择保存路径（PNG 格式）
- **录屏**：点击「开始录制」开始屏幕录制，点击「停止录制」结束

> 注意：录屏功能在 Android 16+ 未 root 设备上可能受 SELinux 限制而无法使用。应用会自动检测支持状态并给出提示。

### 7. 性能监控

- 实时展示 CPU 使用率（含历史曲线）、内存使用量/总量、设备温度
- 进程列表展示各进程的 CPU 和内存占用
- 数据自动刷新，可手动刷新

### 8. 任务中心

- 查看所有批量任务（批量安装、批量卸载）
- 实时显示任务进度（通过进度条和百分比）
- 支持取消正在执行的任务
- 支持清理已完成的任务
- 每个任务显示成功/失败的详细结果

### 9. 显示调节

- 查看当前屏幕分辨率、密度（DPI）、过扫描参数
- 内置常用分辨率/密度预设，一键应用
- 修改过扫描（left/top/right/bottom 四个方向）
- **失败回滚**：设置失败时自动恢复原始值
- 点击「恢复默认」重置为出厂设置
- **系统参数**：调节动画速度、字体大小、锁屏超时

> 警告：设置不兼容的分辨率可能导致屏幕显示异常，失败回滚机制会在出错时自动恢复。

### 10. 电池管理

- 查看当前真实电池状态：电量百分比、温度、充电状态
- **模拟电量**：设置任意电量百分比（1-100）
- **模拟温度**：设置电池温度（20-60°C）
- **模拟充电状态**：设置充电中/未充电/已充满等状态
- **一键还原**：点击还原，取消所有模拟，恢复真实电池读数（带确认弹窗）

> 注意：模拟状态会覆盖设备真实电池读数，还原前设备电池显示可能异常。仅用于开发和测试场景。

### 11. 自动化脚本

- 在文本框中编写多行 ADB 命令脚本
- 支持 `loop` / `end` 循环语法
- 点击「执行」开始流式执行，每行命令按顺序执行
- 实时显示行号级进度和输出
- 支持中途「停止」执行
- 支持脚本的导入和导出（文本文件）
- **输入模拟**：点击（tap）、长按（longPress）、滑动（swipe，可设时长）、物理按键（keyevent）、文本输入（text），带坐标校验
- **设备重启**：重启到 normal / recovery / bootloader 模式（带确认弹窗）

### 12. 设置

- **ADB 路径**：预留项，留空使用内置 adb_client 库
- **主题切换**：亮色 / 暗色主题
- **超时设置**：ADB 命令默认超时时间（1-120 秒）
- **轮询间隔**：设备列表降级轮询间隔（1000-30000 毫秒）
- **图标缓存目录**：应用图标缓存目录（相对路径基于应用启动运行目录，默认 ./cache/icons），可浏览选择
- 设置项通过 localStorage 持久化保存

## 浏览器 Mock 模式体验

如果您没有 Android 设备，也可以通过浏览器体验 adbUI 的界面和部分功能：

```bash
pnpm dev
```

浏览器模式下，设备数据为内置的模拟数据，所有需要真实设备交互的操作会显示提示信息。此模式主要用于前端开发和 UI 调试。

## 常见问题 FAQ

### Q: 设备未识别，列表为空？

- 确认设备已开启「USB 调试」（开发者选项中）
- 确认 USB 线支持数据传输（部分线仅支持充电）
- 在设备上允许 USB 调试授权弹窗
- 尝试重新插拔 USB 线或重启 adbUI

### Q: 无线连接失败？

- 扫码配对需 Android 11+ 且设备与电脑处于同一局域网
- 手动输入前，设备需先通过 `adb tcpip 5555` 开启无线调试（首次需 USB 连接授权）
- 扫描连接依赖局域网 mDNS，部分路由器可能屏蔽 mDNS 广播，可尝试手动输入 IP
- 确认防火墙未拦截 adb 端口（默认 5555）

### Q: 设备状态显示 "Unauthorized"？

- 在设备上撤销所有 USB 调试授权，重新插拔后重新授权
- 确认设备屏幕已解锁

### Q: 录屏按钮不可用？

- Android 16+ 未 root 设备受 SELinux 限制，可能无法使用录屏功能
- 应用会自动检测并在界面上提示
- 已 root 设备通常不受此限制

### Q: 冻结系统应用后设备异常？

- 冻结系统应用有风险，可能导致设备不稳定或无法启动
- 如遇到问题，可通过 adb 命令行恢复：`adb shell pm enable <package>`

### Q: 性能监控数据不更新？

- 确认设备已连接且状态为 Online
- 部分设备可能不支持某些性能指标，会显示为 N/A

### Q: 如何切换语言？

- 当前版本界面为中文，文档提供中英双语版本
- 界面语言切换功能将在后续版本中添加
