## 简介与功能总览

adbUI 是一款基于 Tauri (Rust + Vue) 的跨平台 ADB (Android Debug Bridge) 桌面应用。它通过图形化界面替代繁琐的命令行操作，让您轻松管理 Android 设备。

目前提供 **16 个功能模块**：

| 模块 | 一句话说明 |
|------|-----------|
| 设备管理 | 自动检测已连接设备，展示品牌、型号、Android 版本等详细信息 |
| 应用管理 | 查看设备上所有应用，支持卸载、冻结、提取 APK 等操作 |
| 文件管理 | 浏览设备文件系统，支持上传和下载文件 |
| 日志查看 | 实时查看设备 logcat 日志输出，支持按级别筛选 |
| Shell 终端 | 交互式执行 ADB Shell 命令，支持历史记录和错误高亮 |
| 截图录屏 | 设备截图预览与保存，屏幕录制（部分设备受限） |
| 性能监控 | 实时展示 CPU、内存使用率和进程列表 |
| 命令历史 | 记录本会话执行过的所有命令，支持查看和清空 |
| 任务中心 | 批量操作（安装/卸载）的进度跟踪与管理 |
| 设备信息报告 | 聚合 getprop 与 dumpsys 输出，展示设备完整信息 |
| 显示调节 | 查看和修改屏幕分辨率、密度、过扫描参数 |
| 电池模拟 | 模拟电量、温度和充电状态（恢复真实电池） |
| 设备控制 | 重启设备到不同模式，模拟触摸/滑动/按键输入 |
| 自动化脚本 | 多行 ADB 命令脚本流式执行，支持循环和进度跟踪 |
| 常用命令库 | 收藏常用命令，一键快速执行 |
| 设置 | 主题切换、超时设置、轮询间隔调整 |

## 安装

### 系统依赖

adbUI 基于 Tauri 2 构建，在 Linux 上需要以下系统依赖：

```bash
# Debian / Ubuntu
sudo apt update
sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file libxdo-dev libssl-dev pkg-config

# 确保已安装 Node.js (>= 18) 和 pnpm
# 参见 https://v2.tauri.app/start/prerequisites/
```

### 从源码构建

```bash
# 1. 克隆仓库
git clone <repository-url>
cd adbUI

# 2. 安装前端依赖
pnpm install

# 3. 启动桌面端（开发模式）
pnpm tauri dev

# 4. 打包桌面应用（生成 .deb 安装包）
pnpm tauri build
```

打包完成后，安装包位于 `src-tauri/target/release/bundle/deb/` 目录下。

> 注意：adbUI 通过 Rust 库 `adb_client` 直连 ADB 服务，**无需**本机单独安装 adb 命令行工具。

## 快速上手

### 连接设备

1. **USB 连接**：在 Android 设备上开启「开发者选项」->「USB 调试」，通过 USB 线连接到电脑
2. **WiFi 连接**：设备与电脑处于同一局域网，通过 `adb tcpip 5555` + `adb connect <ip>:5555` 连接（首次需 USB 授权）

### 界面布局

adbUI 界面分为两大区域：

- **左侧边栏**：16 个功能模块的导航入口，点击切换视图
- **右侧主内容区**：当前选中模块的操作界面

首次启动时，adbUI 会自动检测已连接的设备并展示在「设备管理」页面。

## 各功能模块详解

以下按侧边栏顺序逐一说明。

### 1. 设备管理

- 自动轮询（默认 3 秒间隔）检测已连接设备
- 显示设备 ID、型号、连接方式（USB / WiFi）
- 点击设备查看详情：品牌、Android 版本、SDK 版本、构建号、电量等
- 点击「刷新」按钮手动刷新设备列表

### 2. 应用管理

- 查看设备上所有已安装应用，支持按「全部 / 用户应用 / 系统应用」筛选
- **卸载应用**：选中应用后点击卸载（系统应用需 root）
- **强制停止**：立即停止应用运行
- **清除数据**：重置应用数据（相当于「清除存储」）
- **冻结 / 解冻**：禁用/启用应用（系统应用需 root，谨慎操作）
- **提取 APK**：将应用 APK 导出到本地
- **安装 APK**：选择本地 APK 文件安装到设备
- **批量卸载 / 批量安装**：通过任务中心跟踪进度

> 警告：冻结系统应用可能导致设备不稳定，请谨慎操作。

### 3. 文件管理

- 浏览设备文件系统，支持目录导航和面包屑路径
- **上传文件**：点击上传按钮，选择本地文件推送到设备当前目录
- **下载文件**：选中文件后点击下载，拉取到本地

### 4. 日志查看

- 实时捕获设备 logcat 输出
- 支持按日志级别筛选（Verbose / Debug / Info / Warn / Error / Fatal）
- 日志自动滚动，可暂停查看

### 5. Shell 终端

- 交互式 ADB Shell 命令执行
- 支持命令历史记录，按上下键快速回看
- 错误输出高亮显示
- 输入命令后按回车执行，输出实时显示

### 6. 截图录屏

- **截图**：点击「截图」按钮，预览设备当前画面
- **保存截图**：点击「保存」按钮，通过系统对话框选择保存路径（PNG 格式）
- **录屏**：点击「开始录制」开始屏幕录制，点击「停止录制」结束

> 注意：录屏功能在 Android 16+ 未 root 设备上可能受 SELinux 限制而无法使用。应用会自动检测支持状态并给出提示。

### 7. 性能监控

- 实时展示 CPU 使用率、内存使用量/总量、设备温度
- 进程列表展示各进程的 CPU 和内存占用
- 数据自动刷新，可手动刷新

### 8. 命令历史

- 记录本会话通过 Shell 终端执行的所有命令
- 展示命令内容、输出、退出码和执行时间
- 支持一键清空历史记录

### 9. 任务中心

- 查看所有批量任务（批量安装、批量卸载）
- 实时显示任务进度（通过进度条和百分比）
- 支持取消正在执行的任务
- 支持清理已完成的任务
- 每个任务显示成功/失败的详细结果

### 10. 设备信息报告

- 聚合 `getprop` 和 `dumpsys` 输出
- 展示设备完整信息：型号、品牌、Android 版本、CPU 架构、序列号、电池状态、显示参数等

### 11. 显示调节

- 查看当前屏幕分辨率、密度（DPI）、过扫描参数
- 修改分辨率、密度（输入数值后应用）
- 修改过扫描（left/top/right/bottom 四个方向）
- **失败回滚**：设置失败时自动恢复原始值
- 点击「恢复默认」重置为出厂设置

> 警告：设置不兼容的分辨率可能导致屏幕显示异常，失败回滚机制会在出错时自动恢复。

### 12. 电池模拟

- 查看当前真实电池状态：电量百分比、温度、充电状态
- **模拟电量**：设置任意电量百分比（0-100）
- **模拟温度**：设置电池温度
- **模拟充电状态**：设置充电中/未充电/已充满等状态
- **恢复真实电池**：点击恢复，取消所有模拟

> 注意：电池模拟需要 root 权限，仅用于开发和测试场景。

### 13. 设备控制

- **重启设备**：支持重启到 system / recovery / bootloader / fastboot 模式
- **输入模拟**：
  - 点击（tap）：模拟屏幕点击，输入 X Y 坐标
  - 滑动（swipe）：模拟屏幕滑动，输入起始和结束坐标
  - 按键（keyevent）：模拟物理按键（如电源键、音量键）
  - 文本输入（text）：向设备输入文本字符串

### 14. 自动化脚本

- 在文本框中编写多行 ADB 命令脚本
- 支持 `loop` / `end` 循环语法
- 点击「执行」开始流式执行，每行命令按顺序执行
- 实时显示行号级进度和输出
- 支持中途「停止」执行
- 支持脚本的导入和导出（文本文件）

### 15. 常用命令库

- 内置常用 ADB 命令模板（如查看设备信息、清除应用数据等）
- 支持收藏常用命令，一键快速执行
- 支持添加、编辑、删除自定义命令
- 数据通过 localStorage 持久化保存

### 16. 设置

- **主题切换**：亮色 / 暗色主题
- **超时设置**：ADB 命令超时时间
- **轮询间隔**：设备列表自动刷新间隔（默认 3 秒）
- 设置项通过 localStorage 持久化保存

## 浏览器 Mock 模式体验

如果您没有 Android 设备，也可以通过浏览器体验 adbUI 的界面和部分功能：

```bash
pnpm dev
```

浏览器模式下，设备数据为内置的模拟数据，所有需要真实设备交互的操作会显示提示信息。此模式主要用于前端开发和 UI 调试。

## 常见问题 FAQ

### Q: 设备未识别，列表为空？

- 确认设备已开启「USB 调试」（开发者选项中）
- 确认 USB 线支持数据传输（部分线仅支持充电）
- 在设备上允许 USB 调试授权弹窗
- 尝试重新插拔 USB 线或重启 adbUI

### Q: 设备状态显示 "Unauthorized"？

- 在设备上撤销所有 USB 调试授权，重新插拔后重新授权
- 确认设备屏幕已解锁

### Q: 录屏按钮不可用？

- Android 16+ 未 root 设备受 SELinux 限制，可能无法使用录屏功能
- 应用会自动检测并在界面上提示
- 已 root 设备通常不受此限制

### Q: 冻结系统应用后设备异常？

- 冻结系统应用有风险，可能导致设备不稳定或无法启动
- 如遇到问题，可通过 adb 命令行恢复：`adb shell pm enable <package>`

### Q: 性能监控数据不更新？

- 确认设备已连接且状态为 Online
- 部分设备可能不支持某些性能指标，会显示为 N/A

### Q: 如何切换语言？

- 当前版本界面为中文，文档提供中英双语版本
- 界面语言切换功能将在后续版本中添加
